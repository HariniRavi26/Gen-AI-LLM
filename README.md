# AI Text Generation App

A Streamlit-based AI Text Generation application that generates text based on user-provided prompts using a Hugging Face Transformer model.

## Live Demo

https://harini-text-generation.streamlit.app/

## Features

- AI-powered text generation
- User-friendly Streamlit interface
- Custom text prompts
- Adjustable text generation parameters
- Hugging Face Transformer model integration

## Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- Python Libraries
